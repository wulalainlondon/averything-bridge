This public commit snapshots the qualified build source without importing private development history. Source and package provenance are separate from device installation and human acceptance.

Changes since the previous public release include bounded history and native catalog synchronization, source-bound task and question handling, inbox and dispatch controls, native media and LINE service integrations, and collaboration workspace contracts (rooms, posts/reactions, Canvas revisions, ACL and replay protection). Collaboration remains explicitly enabled with `--collaboration-workspace`. Capabilities depend on the installed authenticated provider and device; publication does not create credentials, pairing or grants.

Apple Silicon uses the unchanged signed/notarized package active on the original machine. Intel is a same-source cross-build with target-native remote helpers and a target-specific pinned Node dependency. Intel hardware, complete collaboration matrices, external account effects and human audio are not newly qualified by this publication. Included remote desktop helpers require macOS 14; do not infer full remote-desktop support on older macOS from the core bundle's minimum version.

Use the fixed release tag and original-data update procedure. Existing work, identity, native daemons and LINE configuration must be preserved; never overwrite a live data directory with another machine's state. Linux/Windows packages are not published for this release. Earlier public tags/assets remain available.
