# Averything App Review demonstration

[Download the physical iOS demonstration video](https://raw.githubusercontent.com/wulalainlondon/averything-bridge/app-review-1.3.77/docs/app-review/1.3.77-187/physical-ios-demo.mp4)

Version 1.3.77 (187). Recorded on a physical iPhone 11 running iOS 26.5, paired over the local network with a real user-owned Mac Bridge 0.2.76. The development-signed device installation was exported from the same final archive as the App Store build.

The edited chapters show desktop pairing, browsing real desktop files, starting a read-only Codex session, sending a request and receiving the real desktop response, saving an image through the iOS Share Extension and adding a caption to the draft, downloading a generated ZIP with progress, native file preview, notification settings and the installed version. Permission and service explanations are clearly labeled title cards. This device already had some permission choices from previous use; first-time prompts are conditional.

No private conversation content or credentials are included. Demonstration files and images were generated for review.
